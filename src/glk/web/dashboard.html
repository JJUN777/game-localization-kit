    Edit translation prompt

    번역 프롬프트 설정

    직접 수정한 내용은 API 호출 없이 저장합니다. AI 초안은 승인 원문의 대표 문장을 분석하며, 확인 후 선택해야 편집창에 반영됩니다.

    용어집, 숫자, token과 블록 보존 규칙보다 우선할 수 없습니다.

    AI 초안이 입력되었습니다. 내용을 확인한 뒤 프롬프트를 저장하세요.

    승인한 원문의 앞부분과 일부 규칙 문장을 참고해 번역 지침 초안을 만듭니다. 초안을 적용한 뒤 프롬프트 저장을 눌러야 저장됩니다.

      Background source job
      
          
      원문 준비 시작
      
        
      
        
      
      

      
      
        선택한 AI API를 사용해 원문을 추출한 뒤 검수 블록 생성과 로컬 QA까지
        백그라운드에서 실행합니다. API 사용량에 따라 비용이 발생할 수 있습니다.
      
      
      
      
        
        
      
      
      
      
        
      
          원본 형식
          
        
      
        
      
          사용 모델
          
        
      
      
      
      
      
        
        
        
      
          실행 전 확인용 읽기 전용 내용입니다. 변경하려면 취소한 뒤 프로젝트
          카드의 설정 > OCR 프롬프트 수정을 사용하세요.
        
      
      
      
      
      
        동시에 하나의 원문 준비 작업만 실행합니다. 실행 중에는 원본 교체,
        OCR 프롬프트 수정과 프로젝트 삭제가 잠깁니다.
      
      

      
      
        
        
      
      
    
      
        

  
    
      
      
      
        
      
          
      Local terminology job
      
          
      용어 후보 생성
      
        
      
        
      
      

      
      
        최종 승인된 원문에서 반복되는 이름과 게임 용어 후보를 수집해
        검수용 TSV를 만듭니다. 이 작업은 AI API를 사용하지 않으며
        비용이 발생하지 않습니다.
      
      
      
      
        
        
      
      
      
      
        생성이 끝나면 용어 검수 버튼이 활성화됩니다. 기존 검수 파일이
        오래된 경우에는 사용자 편집을 보호하기 위해 자동으로 덮어쓰지 않습니다.
      
      

      
      
        
        
      
      
    
      
        

  
    
      
      
      
        
      
          
      Background translation job
      
          
      초벌 번역 시작
      
        
      
        
      
      

      
      
        최종 승인 원문과 확정 용어집을 선택한 AI에 보내 초벌 번역과 검수 파일을
        만듭니다. 청크마다 API를 호출하므로 입력량과 모델에 따라 비용이
        발생할 수 있습니다.
      
      
      
      
        
        
      
      
      
      
        
      
          사용 모델
          
        
      
        
      
          실행 방식
          
        
      
      
      
      
      
        
      
          
          
      
            
            
          
      
        
      
        
        
      
          
      
            이번 번역에 적용할 문체와 표현 지침입니다.
          
      
          
        
      
      
      
      
      
        중간 실패 뒤 이어하기에서는 저장된 청크의 입력 hash를 보호하기 위해
        번역 지침을 변경할 수 없습니다.
      
      
      
      
        기존 번역·검수·최종 출력은 revisions에 보관한 뒤 새 프롬프트로 전체
        재번역합니다. 성공하면 번역 검수는 새 초벌을 기준으로 초기화됩니다.
      
      

      
      
        
        
      
      
    
      
        

  
    
      
      
      
        
      
          
      Move to trash
      
          
      프로젝트 삭제
      
        
      
        
      
      

      
      
        프로젝트 폴더 전체를 운영체제 휴지통으로 이동합니다. 휴지통을 비우기
        전에는 Finder 또는 파일 탐색기에서 복구할 수 있습니다.
