# 프로젝트 공통 OCR 추가 지침

이 파일은 이 프로젝트의 모든 이미지 OCR 요청에 공통으로 전달됩니다.
기본 OCR 엔진이 원문 보존, 읽기 순서, block 분리, 좌표와 판독 불가 처리를
담당하므로 여기에는 해당 게임에만 필요한 규칙을 적으세요.

사용하지 않는 안내 문장과 예시는 삭제하거나 프로젝트 내용으로 교체해도 됩니다.

## 프로젝트별 아이콘 token

규칙상 의미가 있는 아이콘을 일관된 token으로 보존해야 할 때만 아래 형식으로
정의하세요.

- 실제 token은 영문 이름의 앞뒤를 ASCII 중괄호로 감싸서 작성합니다.
- 색상만 쓰지 말고 실루엣, 내부 문양, 테두리와 방향처럼 이미지에서 확인할 수
  있는 특징을 구체적으로 적습니다.
- 서로 비슷한 아이콘은 구분 기준을 함께 적습니다.
- 정의하지 않았거나 확실히 판별할 수 없는 아이콘은 임의의 token으로 추측하지
  말고 `[ICON: concise visible description]`으로 기록하고 warning을 남깁니다.

아래 항목은 작성 형식만 보여주는 가상 예시이며 실제 OCR 규칙이 아닙니다.
프로젝트에 맞는 실제 token 정의로 교체하기 전에는 적용하지 마세요.

```text
- TOKEN_NAME: 아이콘의 실루엣, 내부 문양, 테두리, 방향과 색상 설명.
```

## 읽기 순서와 영역별 추가 규칙

게임 화면이나 카드의 고정 배치 때문에 기본 읽기 순서만으로 부족할 때 작성하세요.
예를 들어 제목, 비용, 본문, 하단 식별자의 순서나 제외할 장식 영역을 지정할 수
있습니다. 실제 프로젝트 규칙이 없다면 이 절은 비워 두세요.

## 고유명사와 표기 보존

OCR 단계에서는 번역하거나 문장을 다듬지 않습니다. 특별히 혼동하기 쉬운 문자,
대소문자, 제품 코드 또는 고유 표기가 있을 때만 이미지에서 확인 가능한 기준을
작성하세요. 문맥만으로 보이지 않는 글자를 추측하도록 지시하지 마세요.
